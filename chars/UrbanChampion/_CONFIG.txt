; GUIDE TO CONFIGURATION VIA PALETTE
;=======================================

;Only want certain configurations to appear on certain palettes?
;Here's how to do it:

;Instead of "1", type "(palno = X)", X being whatever palette you want the
;configuration to be active on.

;For example, "var(40) = (palno = 9)" enables 2010 Mode, but only
;on Urban Champion's 9th palette.

;For higher numbers, type "(palno = X)*[number]", X being whatever palette 
;you want the configuration to be active on.

;For example, "var(40) = (palno = 9)*2" enables Boss Mode, but only
;on Urban Champion's 9th palette.

;To include multiple palettes, type "(palno = [X,Y])", with X being the 
;lowest numbered palette, and Y being the highest numbered palette.

;For example, "var(40) = (palno = [7,12])" will make 2010 Mode active
;on palettes 7, 8, 9, 10, 11, and 12.
