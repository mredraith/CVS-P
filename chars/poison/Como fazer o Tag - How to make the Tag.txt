	Acrescente o arquivo "TagBattle5.cns" no diretório de seu personagem e faça as modificações abaixo:

MODIFICAÇÕES NO ARQUIVO CMD:

	Acrescente no "Super Motions":

[Command]
name = "DoubleDragon"
command = ~D, DF, F, c+z
time = 15

[Command]
name = "DoubleDragonCounter"
command = ~B, DB, D, c+z
time = 15

[Command]
name = "DoubleDragonCross"
command = ~D, DB, B, c+z
time = 15


	Acrescente logo após o "Hold Dir":

[Command]
name = "hold_z"
command = /$z
time = 1

	Acrescente logo após o "2/3 Button Combination":

;-| PartnerChange |-----------------------------------------------
[Command]
name = "troca"
command = z+c
time = 1

[Command] 
name = "Assist"
command = y+b
time = 1

	Acrescente logo após o "[Statedef -1]":

MODIFICAÇÕES NO ARQUIVO CNS:

	Se seu personagem usa o [Statedef -3], copie os comandos do arquivo TAGBATTLE4.CNS entre as linhas:

;******** TAG-TEAM (START):

;******** TAG-TEAM (END):

	E cole-os após o "[Statedef -3]" do arquivo CNS de seu personagem.
	Isso é necessário porque o MUGEN não consegue ler essas instruções duas vezes.
	Se eu personagem não usa [Statedef -3], não precisa modificar nada.
