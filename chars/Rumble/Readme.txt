I. INTRODUCTION
-------------------------------------------------------------------------------
Thank you for downloading Rumble McSkirmish CVS/PotS Style. This character is built in the 
"PotS" style—a technical hybrid of Capcom vs. SNK 2 and Street Fighter Alpha 
mechanics. It features high-quality sprites, color separation, and a deep 
gameplay system designed for competitive M.U.G.E.N play.

Don't forget to check CONFIG.txt to change some details in gameplay.

-------------------------------------------------------------------------------
II. SYSTEM FEATURES
-------------------------------------------------------------------------------
This character uses a customized "Groove" system common to PotS-style edits:

- PARRYING (P-Groove): Tap Forward or Down just before an attack hits.
- ROLLING (C-Groove): Press LP + LK to dodge through projectiles/attacks.
- CUSTOM COMBO (A-Groove): HP + HK (Requires 2 bars). 
- POWER CHARGE (S-Groove): Hold MP + MK to manually charge meter.
- EX SPECIALS: Perform a special move with two punch/kick buttons. 
- ALPHA COUNTER: Press F + LP + LK while blocking (Costs 1 bar).
- LEVEL 3 SUPER: Exclusive "MAX" versions of Supers.

-------------------------------------------------------------------------------
III. KEY CONFIGURATION
-------------------------------------------------------------------------------
X - Light Punch (LP)        A - Light Kick (LK)
Y - Medium Punch (MP)       B - Medium Kick (MK)
Z - Heavy Punch (HP)        C - Heavy Kick (HK)
S - Start (Taunt)
